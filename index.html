What it does

Three jobs, one graph

01

Know who everybody is

163,262 merges refused by hard rules
02

Notice the contradictions

Confluence says Benji owns it. Slack says Liam. Those two are wired together, so "what do we disagree about" is one question — not a search.

816 contradiction edges · 75 supersessions
03

Pick a side, and say why

A reviewed page beats a chat message. Newer beats older. Two sources beat one. No model is asked — so the same claims settle the same way every time.

10 shuffled runs · byte-identical verdicts

Run it yourself

Four commands

terminal
# clone, install, start the engine
git clone https://github.com/Shrujal00/glasshouse-hydradb.git
cd glasshouse-hydradb
python -m venv .venv && .venv/bin/pip install -e ".[dev]"
docker compose up -d

# 183 tests, no network needed
.venv/bin/python -m pytest

# open http://127.0.0.1:8080
.venv/bin/python -m uvicorn glasshouse.server:app \
    --host 127.0.0.1 --port 8080 --app-dir src
