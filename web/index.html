Core Principles

Deterministic, provable graph reasoning built on HydraDB.

One Node Per Entity

Disambiguates @priya, priya_nair@redwood.com, and Priya Nair into a single canonical person node.

Full Source Provenance

Every relationship carries document URI, page numbers, and exact timestamps. Zero detached claims.

Conflict Arbitration

When sources disagree, both facts survive. Timestamp and authority priors determine the active winner.

Honest Abstention

When facts are absent from the corpus, Glasshouse explicitly refuses to speculate or hallucinate.

Live Query Terminal

Inspect identity resolution, arbitration, and citation traces in real-time.
